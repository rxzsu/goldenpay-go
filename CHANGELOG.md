# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-08-03
### Added
* **Advanced Webhooks**: Introduced structured `WebhookEvent` parsing for `NewOrder` and `NewMessage` events instead of raw JSON.
* **Review System**: Added `LeaveReview` endpoint for rating buyers.
* **Order Management**: Added `RefundOrder` and `DeleteOffer` APIs.
* **Examples**: Added `webhook_bot` example to demonstrate new webhook types.
